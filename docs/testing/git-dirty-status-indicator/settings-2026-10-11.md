## Поведение

Настройки Git используют тот же `GitStatusViewModel`, что шапка. Enabled file source показывает files/commits/conflicts/time, busy/error/stale; disabled явно сообщает об отключении без historical counters. Header появляется только для включённой синхронизации файлового пространства с завершённой проекцией его настроек. Наличие `.git` само по себе не включает индикатор; включённое пространство без репозитория остаётся visible Unknown. Server скрывает header и показывает not-applicable в настройках.

Off/on прекращает чтение и отвергает старый read epoch, сохраняя operation IDs того же source. Remote/branch update обновляет только read context. Source switch очищает старые samples/operations; transient projection marker предотвращает смесь полей A/B. Captured runtime token связывает Started/Terminal с источником, даже когда binding queued. Replacement/DC detach снимают subscriptions, закрывают popup и очищают его focus; обычный Escape возвращает focus текущему eligible индикатору.

Нет новых persisted fields/schema, Git commands/algorithms или второго observer. Существующие legacy backup status/actions/conflicts сохранены.
