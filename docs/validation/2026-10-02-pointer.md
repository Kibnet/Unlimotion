## Исправление HTTP→SSH, 2026-10-04

Падение Headless из CI [37148466213](https://github.com/Kibnet/Unlimotion/actions/runs/37148466213) воспроизведено локально. `ApplyRemoteConnectionTypeSwitch` выбирал новый remote до обновления `ItemsSource`; настоящий ComboBox записывал сброшенный выбор обратно в VM. Исправление сначала обновляет metadata, затем применяет возвращённые сервисом имя и URL. Общего подавления null, смены Git-алгоритма или ослабления assertions/таймаутов нет.

Также исправлен Headless harness: реальный `Button.OnClick` и завершение асинхронной команды находятся в одном `Session.Dispatch<bool>` scope. Это не даёт PerTest dispatcher завершиться до continuation команды. Отдельный `TaskCompletionSource(RunContinuationsAsynchronously)` переносит продолжение теста с queue worker, исключая deadlock при следующем синхронном Page вызове. Ошибки и cancellation передаются вызывающему тесту.

Контроль причинности с одинаковым scoped harness: новый product порядок — **1 PASS**; старый — **1 FAIL** с прежним `Selected Git remote state was not updated`. После восстановления fix расширенный Headless class — **2 PASS / 0 FAIL / 0 skips**. Regression проверяет реальный `ComboBox.SelectedItem`, имя/URL/режим, refresh, SSH→HTTP и отсутствие дополнительных remotes. Отдельный unit regression перечитывает JSON-конфигурацию после обоих переходов.

Локальные logs/TRX/HTML: `artifacts/remote-selection-fix/`; negative control — `negative-control.log`, расширенный UI — `extended.log`, диагностика deadlock — `scoped-stacks.txt`. Временная trace-инструментализация удалена, dump остаётся local-only. SettingsViewModel — **74 PASS / 0 FAIL / 0 skips** (`settings-unit.log`), включая чтение сохранённого JSON; Release builds main/Headless/FlaUI — **0 errors**.

Локальные полные наборы **не дали PASS**. Headless остановлен общим пределом 10 минут после 19 PASS, 0 test failures, exit 3 (`headless.log`); dump зафиксировал файловый `CreateFilePrivate` при создании MainWindowViewModel, а свободный Headless worker исключает ранее обнаруженный цикл ожидания своей очереди. Повторный dump не получен: процесс уже завершился по лимиту. Main остановлен после более 7 минут и трёх failures: `DisabledWatcherIdentityRaisedDuringCacheHydration_IsDiscarded`, `ServerStorageCrudRealtimeScenario_ExecutesFeatureSteps`, `Save_ConcurrentStorageInstances_DoNotRaceLockCleanup` (`main.log`). В сборке main были disk-full copy retries, позднее проверка показала около 44 ГБ свободного места; файлы не удалялись. Эти наблюдения не доказывают причину всех локальных failures. Повторная полная проверка переносится в CI на отдельный runner; до её результата общий PASS не заявляется.

Нового native video нет: последняя физическая проверка потеряла foreground/input ownership. Для этого исправления fallback — показанное окно с настоящими Avalonia controls в Headless и проверка ComboBox, main suite и сборка FlaUI; pixels и новый physical-pointer PASS не заявляются. Историческая ошибка native Repeater ниже остаётся отдельным ограничением.
